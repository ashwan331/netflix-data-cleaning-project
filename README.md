# Netflix Data Cleaning & Analysis Project

## Project Overview

This project focuses on:
- Data Cleaning using Python
- SQL Analysis using MySQL
- Data Visualization using Python

The Netflix dataset was cleaned, processed, analyzed, and visualized to extract business insights.

---

# Technologies Used

- Python
- Pandas
- NumPy
- MySQL
- Matplotlib
- Seaborn

---

# Project Workflow

1. Raw Netflix dataset loaded using Pandas
2. Data cleaning performed:
   - handled null values
   - removed duplicates
   - standardized columns
   - converted date formats
3. Cleaned dataset exported
4. Data loaded into MySQL
5. SQL queries used for analysis
6. Visualizations created using Python
